# Newsletter AIMS

- `../Newsletter-1.html`: HTML principale da modificare per il numero 1.
- `icons/`: icone condivise e licenza Lucide.
- `shared/`: intestazione condivisa.
- `editions/2026-09-n01/images/`: sole immagini specifiche del numero 1.
- `index.html`: ingresso del sito, che apre il file principale.

Per il prossimo numero, duplicare il file HTML nella radice e creare una nuova cartella di immagini sotto editions. Aggiornare i riferimenti nel nuovo HTML senza sovrascrivere le immagini dei numeri già inviati.

Il file HTML principale si trova nella cartella superiore: Newsletter-1.html.
Le copie di sicurezza sono nella cartella _backup esterna a questo repository.
I riferimenti alle immagini sono relativi per l'anteprima locale; per l'invio email saranno convertiti negli indirizzi HTTPS pubblici di GitHub Pages.
